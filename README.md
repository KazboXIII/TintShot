# TintShot

Screenshot, annotation, color picking and floating reference tools for graphic designers, by DesignByKazbo.

[Download Beta 6 for Windows](https://github.com/KazboXIII/TintShot/releases/tag/v0.3.2-beta.6)

Choose **TintShot-VERSION-Setup-x64.exe** for installation and automatic update support, or **TintShot-VERSION-Portable-x64.zip** to run without installing. Requires Windows 10 version 1809 or newer / Windows 11, Intel or AMD x64, and .NET Framework 4.8. ARM Windows is not supported in this beta. The application and installer are unsigned.

- **Ctrl+Shift+2:** capture a region and annotate it on screen.
- **Ctrl+Shift+3:** pick a screen color.
- **Ctrl+Shift+1:** open the design desk.
- **Ctrl+,** or the tray menu: settings and customizable shortcuts.

Beta 6 includes the official update source and fixes HTTPS update checks. **Beta 4/5 users: install Beta 6 manually once** because older builds can fail to connect to GitHub. Installed copies check GitHub Releases after launch and every six hours; you choose when to install. Downloads are checked against GitHub's SHA-256 asset digest. Settings > Updates controls automatic checks and beta releases. Portable copies can check for updates but require manual replacement or installation.

Close an older TintShot or Surge Capture copy before installing. Upgrades preserve the local library and preferences. Data stays in `%LOCALAPPDATA%\SurgeCapture`; there are no capture uploads or telemetry. Closing the main window hides it in the tray by default; choose Quit TintShot to exit.

Each release includes an installer, portable ZIP, beta notes, tester guide and SHA256SUMS.txt. This repository distributes releases and product documentation. Read the beta notes for known limitations and the tester guide before reporting issues.
